# Sauce Demo Shopify – Manual Testing Project

## Project Overview

This project focuses on manual testing of the Sauce Demo Shopify website.

The objective was to evaluate the application's functionality, verify user flows, identify defects, and document testing activities and results.

## Application Under Test

- **Application:** Sauce Demo Shopify
- **Website:** https://sauce-demo.myshopify.com/
- **Testing Type:** Manual Testing
- **Testing Approach:** Functional Testing
- **Project Type:** Individual Portfolio Project

## Scope of Testing

The testing activities covered the following pages and functionalities:

- Login Page
- Forgot Password Page
- Signup Page
- My Account Page
- Addresses Page
- Search
- Home Page
- Catalog / Product Page
- Cart
- Checkout
- Blog and About Us Pages

## Testing Activities

The following testing activities were performed:

- Created and organized test scenarios and test cases.
- Performed positive and negative testing.
- Verified form validations and error messages.
- Tested navigation between pages.
- Tested core end-to-end user flows.
- Executed test cases and documented their results.
- Identified, reported, and tracked defects.
- Captured screenshots and screen recordings as testing evidence.

## Tools Used

- **Jira:** Defect tracking and project management.
- **Zephyr Advanced:** Test case management and test execution.
- **Microsoft Excel:** Test documentation and execution results.
- **ShareX:** Screenshots and screen recordings.
- **GitHub:** Test documentation and portfolio hosting.
